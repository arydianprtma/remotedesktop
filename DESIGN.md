# Design Direction: Remote Desk (Light Theme)

## Identity & Purpose
A refined, modern desktop utility for unattended and attended remote access across networks.

## Style Direction
- Palette (Crafted Light Theme):
  - Canvas Background: #f8fafc (crisp warm slate)
  - Surface Card: #ffffff (pure white)
  - Surface Subdued: #f1f5f9 (soft neutral for secondary panels and input fields)
  - Border Primary: #e2e8f0 (clean structural dividing lines)
  - Border Strong: #cbd5e1 (for inputs and active outlines)
  - Text Primary: #0f172a (deep slate navy, WCAG AAA compliant on white)
  - Text Secondary: #475569 (slate grey, WCAG AA compliant)
  - Text Muted: #64748b
  - Accent / Primary CTA: #2563eb (cobalt blue) with hover #1d4ed8
  - Accent Soft: #eff6ff (light blue tint for focused states)
  - Destructive: #dc2626 with hover #b91c1c
  - Status Indicators:
    - Active / Online: #059669 (emerald) with #ecfdf5 background
    - Standby / Connecting: #d97706 (amber) with #fffbeb background
    - Disconnected / Offline: #dc2626 (ruby) with #fef2f2 background
- Typography:
  - Primary Stack: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
  - Monospace Display: ui-monospace, "Cascadia Code", "Consolas", monospace for Device ID and Latency numbers
- Dials:
  - ENERGY: 1 (calm, focused utility)
  - RHYTHM: 1 (structured, readable)
  - MOTION: 1 (functional state transitions)
